# Projects · 项目卡数据（Data）

> 来源：`server/data/game_data.ts`。所有 `maxEnergy` 为单轮/累计投入上限；`rankRewards` 为 6 人基准的排名奖（按人数缩放，见 data_numeric_config.md）；`overInvestPenalty` 为超上限投爆时的惩罚数组。

## 基础回报与时代加成常量
- 短期基础回报 = `投入 × 10`（仅本轮投资者）
- 长期基础回报 = `累计投入 × 15`（所有历史投资人）
- 风险基础回报 = `投入 × 20`（名含 成瘾/完美/幸福 ×25）
- 时代加成：短期 `ERA_BONUS_POOL_SHORT = 50`、长期 `ERA_BONUS_POOL_LONG = 100`（仅第一名并列组 + 时代契合）
- 点石成金：所有正项 `floor(×1.5)`，惩罚不放大

## 抽卡 / 上桌规则（gameEra.ts）
- 进入每轮时保留上一轮未完成项目，再补抽新项目。
- **时代1轮1**：固定放入「心理学教育普及」（长期），再补 短期×3 + 长期×1 + 风险×1。
- **时代1轮2**：固定放入「城市海绵体改造」「文化桥梁使者」（长期），再补 短期×1 + 长期×1 + 风险×1。
- **时代2–3**：短期×1 + 长期×1 + 风险×1。
- **时代4–5**：短期×2 + 风险×1（不再抽长期）。
- 非本时代主题的风险项目在换代时清除。
