# Special Rule Details（规则特殊细节）

> 本文聚焦「边界、时序、限制、特例」。框架与数值见 rules_framework.md 与 数据_*.md。

---

## 1. 道具卡机制（8 张逐项）

### 1.1 保险（buff_insurance，special，第1场拍卖）
- 在本卡生效轮次内，你**有投入（>0）**的风险项目若**投爆**则赔付 **100**。
- 若同时持「点石成金」，赔付作为正向收益按 **1.5 倍向下取整 → 150**。
- 被动型，结算 / 开奖时自动生效，无需指定目标。

### 1.2 点石成金（buff_gold，gain，第1场拍卖）
- 所有由项目结算、彩票、保险产生的正向收益（基础、排名、时代加成、彩票奖金、保险赔付）按 **1.5 倍向下取整**。
- **第四时代未完成长期项目的梯度奖、退款与转账不放大**；**惩罚不放大**。被动型，本卡生效轮次内有效。

### 1.3 摸鱼传染（buff_slack，interfere，第1/2/3场均可能出现）
- 指定一名在局玩家（**可指定自己**），使其精力 **−8（可低于 0）**。
- 若对方本卡生效轮次内已有「劳逸结合」被动，则改为 **+8 精力**。
- 摸鱼传染、劳逸结合在**每场拍卖各可出现一张**。
- 使对方精力转负时，其已锁定投资自动解锁并退回精力。

### 1.4 强买强卖（buff_force_buy，special，第2场拍卖）
- **仅能在拍卖阶段**使用；**免费**将当前正在拍卖的焦点卡入手。
- **默认整局仅出现一张**；**每张只能用一次**。管理端可手动补发额外副本，补发的每张同样只能用一次。
- 使用后作废当前出价并顺延焦点卡。

### 1.5 劳逸结合（buff_work_rest，special，第1/2/3场均可能出现）
- 指定一名在局玩家（含他人）：该玩家在本卡生效轮次内被「摸鱼传染」时**不减精力而 +8**（不叠层）。
- 发动时**追溯改判本卡生效轮次内已发生的摸鱼**：若目标已有待处理的摸鱼，一并返还并改为 +8。
- 打火机作废某次已被改判的摸鱼时，对应改判的 +8 也同步撤销，不会出现双倍收益。

### 1.6 项目做空（buff_short，special，第2场拍卖）
- 投资阶段（提交锁定前）声明，指定一个本卡生效轮次内可投入的项目。
- **结算页判定**：该项目**全员已积累精力全部清零**（含长期进度、本轮投入，**含使用者自己**）；已入账财富不追回；本轮不再发回报；项目留桌可再投。

### 1.7 打火机（buff_lighter，special，第3场拍卖）
- 发动时机：投资阶段（提交锁定前）；**倒计时最后 2 分钟不可用**。
- 指定另一名玩家 + 一种道具（**不可指定自己或打火机**）；使用时立即消耗打火机；**看不到对方手牌**。
- 全员日志公开「对谁、指定何种卡」；**是否命中不写日志**。
- **结算页、项目结算前统一判定**：先作废本卡生效轮次内已打出的**一张**该种类 → 若没有，再查手牌烧**一张**；**同种类有多张时只处理一张**。
- 手牌命中：**私下提示**，对方**确认后**移除一张；皆无则**无效仍消耗**，详情仅当事人可见。

### 1.8 彩票（buff_lottery，special，第3场拍卖）
- 打出后由系统调用**线上随机源**（random.org；不可用时退回服务端加密随机）掷 1 颗六面骰。
- 点数决定奖金：1→0、2→30、3→60、4→90、5→120、6→200。
- 若在本卡生效轮次内持有「点石成金」，奖金作为正向收益按 1.5 倍向下取整。
- 流程：打出/系统兜底 `createRandomLotteryOffer` → 玩家端看到骰子动画并确认 → 入账并移除彩票 buff。系统自动主持时超时未确认会自动领取；主持仍可撤回修正（待确认直接取消；已开奖则退款并恢复彩票）。

## 2. 结算特殊规则

### 2.1 做空清零
见 §1.6；注意已入账财富不追回，仅清零后续积累。

### 2.2 投爆惩罚
- 短期超上限时，按 `overInvestPenalty` 数组对所有历史投资人扣钱；并列组共享名次池、可均摊。
- **惩罚不被点石成金放大**。

### 2.3 时代加成细节
- 判定：`project.era === 当前时代卡.era` 且为**第一名并列组**。
- 短期仅「恰好满额」发放（投爆无）；长期「累计 ≥ 上限（含超额）」发放。
- 风险永不参与。

### 2.4 点石成金细节
- 仅正项放大；`baseBeforeGold / rankBeforeGold / eraBeforeGold` 保留「金前原值」用于展示。

### 2.5 保险赔付与金
- 保险 100，有金则 150；保险赔付计入正向收益，故受金放大。

### 2.6 第四时代梯度
- 见 rules_framework.md §4.7；按比例 1:1 / 1:5 / 1:10 发梯度奖，不放大金。

## 3. 拍卖规则

### 3.1 场次与卡池（AUCTION_CARD_IDS_BY_ROUND）
- 第1场（进时代2）：保险、点石成金、摸鱼传染、劳逸结合
- 第2场（进时代3）：强买强卖、摸鱼传染、劳逸结合、项目做空
- 第3场（进时代4）：打火机、彩票、摸鱼传染、劳逸结合

### 3.2 公开加价拍卖
- 起拍价 `AUCTION_STARTING_BID = 5`，加价 `AUCTION_BID_INCREMENT = 5`。
- 玩家出价校验：可用财富扣预留后足够、出价 ≥ 最低下一价；AI 与真人同一套规则，可以出价。
- 主持「锤子」`hammerAuctionLot`：赢家 `wealth -= 领先价`、`inventory` 加焦点卡、顺延焦点。
- 「跳过」`passAuctionLot`：跳过当前焦点；仅剩一张则回退起拍价重来。

### 3.3 强买强卖
- 仅 `AUCTION` 阶段、对当前焦点卡；免费拿卡。
- **默认整局仅一张**；每张只能用一次；管理端可补发额外副本，补发副本同样每张一次。

### 3.4 复活 / 撤销
- `revokeAuctionGrant`：待确认报价直接取消；已成交则退款并收手牌。
- 拍卖开场 `beginAuctionSession` 清空所有待确认出价 / 已分配 / 强买记录。
- 旧「填价确认」路径已废弃。

## 4. 咖啡机制
- 花 17 财富换 +1 精力；可多杯；每轮发精力时清零计数。
- 退订：须先调低预填投资使草稿精力不超可退订后精力；退订后精力不足则拒绝。

---

## 5. 彩票机制
- 见 §1.8；打出后由系统线上随机掷骰（1–6 → 0/30/60/90/120/200），玩家确认后入账（有金 ×1.5），记录 `enteredAmount / creditedAmount / goldApplied / roll / source`。
- 随机源优先 random.org，网络异常时退回服务端 `crypto.randomInt`；两种来源都会写入导出。
- 结算前打火机可作废彩票：登记 `wealthCredited`，作废时追回。

## 6. 聊天 / 谈判（产品版默认开启）
- `GROUP_CHAT_ENABLED = true`：下发群数据，允许建群/群消息；关闭时**不下发群数据、拒绝建群/群消息接口**。
- 开启时：含 `__public__` 全场频道 + 自定义群；房间有真人后自动创建全场并同步真人成员，新一局重置后自动重建。
- 每人最多 6 群、每房 24 群、每群 500 消息；单次广播只下发每群最近 200 条。
- 建群须 ≥3 名真人成员（去重后 ≥2）；群主可加人，<2 人自动解散。
- 禁建群阶段：`ROOM_WAITING / ERA_INTRO / TUTORIAL`。消息经违禁词过滤。
- 频率限制：群消息 20 条/分钟，建群 5 次/分钟，加人/退群 10 次/分钟。
- 真人危机消息由服务端统一发送固定安全回复（110/120/12356），只记录类别与消息 ID。

## 7. 主持（管理员）能力
- **系统自动主持** `AUTO_HOST_ENABLED`（产品版默认开）：等待房自动开局、时代介绍/结算自动推进、拍卖自动聚焦/落槌/跳过/结束、彩票自动随机开奖、命名超时兜底。管理端可按房间开关 `adminSetAutoHost`，手动操作始终优先。
- **项目调整** `adminProjectAdjust`：投资/结算阶段可 `stake`（±投入）或 `withdraw`（强制撤场退本轮精力）；带 `hostRevision` 防并发；结算阶段从基线还原重算。
- **发牌 / 收牌** `adminPlayerCard`：向 `inventory` 追加任意卡或移除手牌（支持定位同名多张）；AI 不可操作。
- **投资解锁 / 强制结算 / 跳转** `adminUnlockPlayer / adminForceSettle / adminSkipPhase`：跳到 `ERA_INTRO/ROOM_WAITING` 会重置；跳到 `INVESTMENT/AUCTION` 自动准备对应状态。
- **拍卖主持**：结束拍卖、改焦点、锤子、跳过、撤销。
- **倒计时** `adminInvestmentTimer`：暂停 / 继续 / 重置。
- **彩票 / 财富调整**：彩票为线上随机开奖，玩家确认后入账；财富调整须玩家确认。
- **社交评分** `adminRateSocial`：A–E；**踢人 / 解散房 / 加 AI / 自动对弈调参**。
- **上帝观战** `adminPerspective`：全量下发（卡牌、成交、撤回、设备认领、原额等）。

## 8. AI 玩家（产品版默认开启）
- `AI_PLAYERS_ENABLED = true`：服务端可托管 AI。**严格 Agent 模式**下 AI 决策必须由模型完成；没有 Key、未联网或检测失败时**拒绝添加 AI / 拒绝开局**，不会退回本地规则。
- 产品版 **不预设人格**：提示词只给规则与目标，由模型自由发挥；旧局显式人格仍兼容。
- `aiOrchestrator`：遍历未就绪 AI，输出合法 JSON 决策（买咖啡 → 用卡 → 投资 → 转账/聊天 → ready）。
- AI 与真人平权：可以拍卖出价、成为首富、获得社区命名权、计入社区总财富。
- `autoTuner`：固定 6 槽位跑完整局，局末比对「真值 vs 推断人格」，准确率 <100% 时对权重做爬山式扰动调参。

## 9. 特性与教程开关
- `AI_BOT_ENABLED = true`、`GROUP_CHAT_ENABLED = true`（产品版默认开）。
- 产品版开局：支持 1–6 名真人；不足 6 席时由 AI 补满（严格模式需要对应模型 Key）。
- 教程 `TUTORIAL_SLIDE_COUNT = 8`、`TUTORIAL_MAX_STEP = 7`；主持可 开始/上一步/下一步/结束。
- 人格立绘白名单 6 个（Bridge/Moment/Navigator/Planter/Poet/Wave，对应 6 类命运素描）。
- 客户端版本校验：过旧客户端收到强制更新提示。
- 上传仅允许 JPEG（≤5MB），项目 / 时代 / 道具 / 人格立绘按白名单 id 上传。
