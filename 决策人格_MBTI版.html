一、总览

1.1 核心思想

MBTI（Myers-Briggs Type Indicator）的灵感来自荣格的心理类型理论，将人格拆解为若干正交维度，每个维度代表一种认知偏好的方向。这一设计思路极具普适性：它不评判对错，只描述偏向。

「决策基因」系统 借鉴 MBTI 的四维正交框架，结合行为经济学、博弈论、社会心理学的理论依据，将「光阴对赌」游戏中玩家的实际行为抽象为四个独立维度。每个维度由游戏内的真实操作数据驱动，而非自我申报的问卷。

核心创新点：

  1. 基于行为，而非申报 — 分析玩家实际投入了什么，而不是他们认为自己是什么
  2. 概率而非类别 — 每个维度输出的是倾向程度（百分比），而不是非此即彼的标签
  3. 游戏即测试 — 将社会学实验嵌入娱乐游戏，消除社会期望偏差（Social Desirability Bias）

二、四个维度的学术依据

2.1 Axis L/Q：时间偏好（长线 vs 速决）

对应心理学概念：时间折现（Temporal Discounting）/ 延迟满足（Delayed Gratification）

核心研究依据：

  • 棉花糖实验（Mischel, 1970s）：斯坦福大学沃尔特·米歇尔的经典实验，儿童对即时满足的抵制能力与后来的学业、社交、健康结果显著相关。揭示了人的时间偏好存在稳定的个体差异。

  • 双曲线折现模型（Hyperbolic Discounting）：经济学研究发现人类对时间的折现并非指数级（理性），而是双曲线形：对近未来的折现率急剧高于对远未来的折现率。这解释了"知道要存钱却还是消费"的矛盾。

  • 神经科学依据：长远决策激活前额叶皮层（理性、计划），即时奖励激活边缘系统（情绪、冲动）。时间偏好在神经层面对应"冷/热系统"（Cool/Hot System）的博弈。

  • 投资学验证：巴菲特的"20格打孔"原则——一生只做20次投资决策——是L轴极端表达的现实案例；短线日内交易员的高换手率则是Q轴的典型行为模式。

在游戏中的表现：

  • L（长线）玩家：优先参投长期项目，甘愿放弃即时短线收益，体现"延迟满足"
  • Q（速决）玩家：倾向做完短平快项目，快速回收精力，体现"时间折现率高"

2.2 Axis A/G：风险偏好（进取 vs 防御）

对应心理学/经济学概念：前景理论（Prospect Theory）/ 损失厌恶（Loss Aversion）

核心研究依据：

  • 前景理论（Kahneman & Tversky, 1979）：诺贝尔经济学奖研究发现，人们对损失的痛苦大约是同等收益的快乐的 2倍（Loss Aversion）。风险偏好本质上是个体设定参考点（Reference Point）的方式不同。

  • 大五人格中的开放性（Openness to Experience）：高开放性个体更倾向于新奇刺激、不确定性，与高风险容忍度显著正相关。低神经质（Neuroticism）则与冷静应对风险相关。

  • 心理账户理论（Mental Accounting, Thaler）：风险偏好受"心理账户"影响——已经赚到的钱被放入"安全账户"，人们会对其格外保守；面临确定损失时，人们反而倾向于冒险（Losing Frame Effect）。

  • 进化心理学：在资源匮乏的情境下，冒险是唯一的出路（A轴适应）；在资源充裕时，保护存量才是理性选择（G轴适应）。

在游戏中的表现：

  • A（进取）玩家：参投高风险的"风险项目"，使用做空/彩票道具
  • G（防御）玩家：回避风险项目，专注于回报稳定的常规投资

2.3 Axis D/C：规则态度（破局 vs 守成）

对应社会学/心理学概念：制度颠覆倾向（Institutional Disruption）/ 权威遵从（Obedience to Authority）

核心研究依据：

  • 米尔格拉姆服从实验（Milgram, 1963）：著名的"电击实验"发现，绝大多数人在权威框架下会选择服从，但仍有约35%的人会在某点拒绝。这揭示了人类对规则的遵从本能，以及打破规则所需的心理成本。

  • 熊彼特的创造性破坏（Creative Destruction）：经济理论认为，颠覆性创新是经济进步的核心引擎。能在规则框架外思考的人是少数，但可以重塑整个赛局。

  • 大五人格：高尽责性（Conscientiousness）与遵守规则（C轴）正相关；高开放性（Openness）与愿意打破惯例（D轴）正相关。

  • 结构-能动性辩论（Structure-Agency Debate）：社会学核心辩题：个体是被社会结构所塑造（守成C），还是能反过来改变结构（破局D）？

在游戏中的表现：

  • D（破局）玩家：频繁使用道具卡干预游戏规则，如诅咒、强征、做空等
  • C（守成）玩家：从不或极少使用干预型道具，完全在现有规则框架内运作

2.4 Axis V/R：核心动机（求效 vs 共情）

对应社会心理学概念：成就动机（Achievement Motivation）/ 社会价值取向（Social Value Orientation）

核心研究依据：

  • 麦克利兰成就需求理论（McClelland's Needs Theory）：将人类动机分为成就需求（nAch）、亲和需求（nAff）、权力需求（nPow）。V轴对应高成就需求（结果导向），R轴对应高亲和需求（关系导向）。

  • 社会价值取向理论（SVO, Van Lange, 1999）：将个体对社会资源分配的偏好分为：竞争者（Competitor）、个人主义者（Individualist）、亲社会者（Prosocial）、合作者（Cooperator）。V玩家偏向竞争/个人，R玩家偏向亲社会/合作。

  • 囚徒困境实验：在经济博弈中，V倾向的个体倾向于选择背叛（获得绝对利益），R倾向的个体更倾向于选择合作（维护关系稳定）。

  • 自我决定理论（SDT, Deci & Ryan）：外部动机（金钱、排名）vs 内在动机（关系、意义）。V轴为外部成效导向，R轴为内在意义/关系导向。

在游戏中的表现：

  • V（求效）玩家：ROI效率高，追求每格精力的最大回报，上帝评分较低
  • R（共情）玩家：ROI效率较低，但上帝评分高，注重社交资本积累

3.1 LADV · 长线激进·颠覆操盘手

核心特质：高风险、长周期、打破规则、利益优先 现实原型：对冲基金经理、颠覆性创业者、激进投资人 现实人物参照：早期马斯克、乔治·索罗斯

详细描述： 你是这个游戏里最危险的玩家。你从不在乎单轮的得失，你把每一局都看作一盘长棋。你敢于把全部筹码押在别人不敢碰的高风险项目上，同时毫不犹豫地用道具卡重写规则——不是为了破坏而破坏，而是因为你清楚：规则的制定者比遵守者更有主动权。你对"关系维护"没有太大兴趣，你的社交目的是为了交换价值，而不是经营感情。当游戏结束时，你要么站在财富榜顶端，要么在某轮豪赌中灰飞烟灭。但无论如何，你不会选择另一种活法。

优势：最大化期望收益、擅长主动创造有利局面 风险：过于激进可能全盘皆输、忽视关系导致联盟失败

3.2 LADR · 长线激进·创变布道者

核心特质：高风险、长周期、打破规则、关系优先 现实原型：社会企业家、改革派政治家、颠覆性NGO领袖 现实人物参照：马丁·路德·金、早期阶段的雷军

详细描述： 你相信改变系统不是靠一个人，而是靠一群被点燃的人。你愿意在长期高风险的道路上奔跑，但你跑向的不只是财富，而是影响力。你善用道具打破格局，但每一次出手都带着目的：扩大你的社交版图，把更多人纳入你的轨道。你是那种"先亏三年、再赢十年"的人，你亏的是精力，赢的是信任和资源网络。当你成功时，周围的人不只说"他赚到了"，而是说"因为他，我们都赚到了"。

优势：具备长远战略眼光、善于积累社会资本、有感召力 风险：高风险叠加社交成本，精力消耗巨大

3.3 LACV · 长线顺势·冷酷寡头

核心特质：高风险、长周期、遵守规则、利益优先 现实原型：传统金融大鳄、寡头企业家、体制内的精明收割者 现实人物参照：李嘉诚早期、传统金融机构掌舵人

详细描述： 你从不做任何多余的事。你完全在规则允许的范围内运作，但在这个范围内，你的胆子比所有人都大。你善于利用制度红利，找到规则内最大的套利空间，一次性下重注。你既不需要破坏规则（那样太显眼），也不需要靠感情维系关系（那样太浪费）。你是那种安静地赚到最多的人。当别人还在争论道德与策略时，你已经把结果装进了口袋。

优势：执行力极强、风险可控、收益稳定可复制 风险：缺乏灵活性，规则一旦变化可能反应迟钝

3.4 LACR · 长线顺势·理想领袖

核心特质：高风险、长周期、遵守规则、关系优先 现实原型：传统政治领袖、大型机构掌舵人、有理想的公司董事长 现实人物参照：默克尔、任正非

详细描述： 你相信制度是好的，而你是有能力让它变得更好的人。你不是破坏者，你是改良者。你愿意承担长期高风险，但你的底线是：绝不越线。你的力量来自于你的信誉——因为人们知道你不会突然做出任何出格的事。当你持续赢得他人信任，你的社交资本最终会转化为商业或政治资本。你是那种"做好事也赚大钱"的人，尽管这条路非常慢。

优势：高可信度、强社会资本积累、制度内上升路径清晰 风险：速度慢，容易被更灵活的对手超越

His expression is earnest and calm, one hand holding a scroll with a blueprint. 3.5 LGDV · 长线稳健·破局精算师

核心特质：低风险、长周期、打破规则、利益优先 现实原型：量化策略分析师、利用漏洞的专业投资者、黑客精神的金融工程师 现实人物参照：文艺复兴科技量化团队核心成员

详细描述： 你不冒险，但你会破坏。这个组合让大多数人感到意外——通常人们认为"保守"和"破坏规则"是矛盾的。但对你来说，破坏规则本身就是一种降低风险的策略：你在别人的规则体系里找漏洞，用系统的弱点来保护自己的稳定收益。你的每一步都经过精密计算，道具卡是你的手术刀，而不是武器。你很少在一项投资里亏损，但你也不会等待高风险赌注——你相信聪明就已经足够了。

优势：系统性挖掘制度漏洞、风险极低的超额收益 风险：过于依赖规则漏洞，漏洞消失后可能迷失

3.6 LGDR · 长线稳健·社群架构师

核心特质：低风险、长周期、打破规则、关系优先 现实原型：社区组织者、平台创业者、以关系为护城河的变革者 现实人物参照：扎克伯格（Facebook早期）、滴滴程维

详细描述： 你的武器是网络，不是刀。你花时间建立一个庞大的社交网络，这个网络本身就是你的核心资产。你不冒财务风险，但你愿意打破社会规则——比如打破行业的信息壁垒、重组既有的权力分配。你用道具不是为了伤害别人，而是为了给你的网络创造机会。当你的网络足够庞大，你就成了规则制定者的一员——通过关系，而不是通过暴力。

优势：社交资本极强、打造强黏性生态 风险：初期积累慢，容易被急功近利的对手超越

3.7 LGCV · 长线稳健·隐忍守望者

核心特质：低风险、长周期、遵守规则、利益优先 现实原型：指数基金长期投资者、"慢公司"建设者、延迟满足的极端执行者 现实人物参照：沃伦·巴菲特、查理·芒格

详细描述： 你相信时间是最好的朋友，复利是最公正的裁判。你从不打破规则，因为你知道规则最终会奖励那些最有耐心的人。你不冒险，不浪费社交精力，你只做一件事：不断积累，等待收割。当别人在前三年收了三次小钱，你在第五年突然拿走了所有人的大钱。别人觉得你很无聊，但你知道：你才是最后站着的那个。

优势：最高的长期复利潜力、风险极低 风险：短期排名落后、规则变化时适应力最弱

3.8 LGCR · 长线稳健·温和共建人

核心特质：低风险、长周期、遵守规则、关系优先 现实原型：可靠的团队长期合伙人、传统合作社领袖、家族企业温和守护者

详细描述： 你是最让人放心的那种人。你不会突然做出任何出格的事，你永远守规矩，你的承诺可以被信任。你的目标不是成为最富有的人，而是和所有人一起变好。你的收益来自于"共赢"——当你帮助别人拿到了收益，你也总能分到一杯羹。在高压、高焦虑的竞争游戏中，你是一股清流，也是那个最终被所有人感谢的人。

优势：最受信任的盟友、高上帝评分 风险：过度关系导向，可能被博弈中的理性自利玩家利用

3.9 QADV · 短线激进·高频投机客

四、指标追踪与计算方法

4.1 Axis L/Q：时间偏好（长线 vs 速决）

数据来源：player.investedLongEnergy、player.totalEnergyConsumed、player.investedRiskEnergy

// 长期精力占比
const longRatio = investedLongEnergy / totalEnergy;

// 短期精力估算（总精力 - 长期 - 风险）
const shortEnergyEst = Math.max(0, totalEnergy - investedLongEnergy - investedRiskEnergy);
const shortRatio = shortEnergyEst / totalEnergy;

// 方向得分（正=长线倾向，负=速决倾向）
const longShortScore = (longRatio - shortRatio) * 100;

// 判定方向与百分比
const code = longShortScore >= 0 ? "L" : "Q";
const percent = Math.min(100, Math.max(0, 50 + longShortScore / 2));

解读阈值：

  • 得分 > 20：明显 L（长线）倾向，percent > 60%
  • -20 ~ 20：倾向模糊（接近 50/50）
  • 得分 < -20：明显 Q（速决）倾向，percent > 60%

4.2 Axis A/G：风险偏好（进取 vs 防御）

数据来源：player.investedRiskEnergy、game.totalRiskEnergyAvailable

// 风险参与率 × 权重系数
const riskConservScore = totalRiskEnergyAvailable > 0
  ? Math.min(100, (investedRiskEnergy / totalRiskEnergyAvailable) * 100 * w_risk_ratio)
  : 0;

// 判定方向（50 为中性阈值）
const code = riskConservScore >= 50 ? "A" : "G";
// A 的强度百分比即 riskConservScore，G = 100 - riskConservScore

可补充指标：

  • 使用「彩票」道具 → 额外加分 +10
  • 使用「做空」道具 → 额外加分 +15

4.3 Axis D/C：规则态度（破局 vs 守成）

数据来源：player.usedCards（道具使用记录列表）

// 每张道具卡计 12.5 分，上限 100
const disruptFollowScore = Math.min(100, usedCards.length * 12.5);
// 即：使用 4 张以上道具 → 完全破局倾向(100分)

// 判定方向
const code = disruptFollowScore >= 50 ? "D" : "C";

解读：

  • 0 张道具：守成 C，0%
  • 1-3 张道具：轻度破局，12.5%-37.5%
  • 4+ 张道具：重度破局 D，50%-100%

可改进：按道具类型差异化赋分（主动攻击型诅咒/强征 > 辅助型彩票/延迟型）

4.4 Axis V/R：核心动机（求效 vs 共情）

数据来源：resourceConversion（ROI效率得分 0100）、socialConnection（上帝评分 0100）

// 利益 vs 社交的净差值
const profitSocialScore = roiScore - socialScore;
// 正值 → V（求效），负值 → R（共情）

const code = profitSocialScore >= 0 ? "V" : "R";
const percent = Math.min(100, Math.max(0, 50 + profitSocialScore / 2));

解读阈值：

  • 得分 > 30：明显 V（求效）型
  • -30 ~ 30：两者较均衡
  • 得分 < -30：明显 R（共情）型

高级功能，需要模拟

两者各有含义，可作为单独维度输出，在报告末尾附上说明。
